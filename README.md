## What I'm building

Small single-purpose web tools that run entirely in your browser: no sign-ups, no uploads.

- **[Discord Timestamp Generator](https://discordtimestampgen.com)**: turn any date, time and timezone into Discord `<t:…:F>` codes everyone sees in their own local time
- **[FontGlitch](https://fontglitch.com)**: zalgo / glitch text generator plus 17 Unicode font styles
- **[Metadata Remover AI](https://metadataremoverai.com)**: strip GPS, EXIF, C2PA and AI-generator metadata from photos and videos losslessly, in the browser
- **[EmojiDig](https://emojidig.com)**: find any emoji by meaning or slang and copy the exact character

The engines are open source: [lossless-metadata](https://github.com/fazal-bhinder/lossless-metadata), [zalgo-kit](https://github.com/fazal-bhinder/zalgo-kit), [discord-timestamp-kit](https://github.com/fazal-bhinder/discord-timestamp-kit). Each site also has a free remote MCP server at `/mcp` for AI assistants.
